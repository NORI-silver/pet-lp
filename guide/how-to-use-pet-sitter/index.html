ペットシッターの頼み方：打ち合わせ・鍵・報告・保険まで、初めての流れ

留守のあいだ、いつもの家で待っていてほしい。ペットシッターは、そのための選択肢です。初めて頼むときの流れと、確かめることをまとめました。

流れ：問い合わせから鍵の返却まで

ペットシッターSOSの「ご利用の流れ」では、次の順で進むと説明されています。ほかのグループや個人のシッターも、だいたい同じ流れです。

  1. 問い合わせ：日程が決まったら、近くの店舗に連絡する
  2. 事前の打ち合わせ：初めてのときは担当のシッターが自宅に来て、性格・健康・日課を聞き、ペットの記録をつくる。犬は散歩のコースを一緒に歩くこともある
  3. 契約と支払い、鍵：見積もりに納得したら契約。留守のときは合鍵を預け、会社の決まりで管理する
  4. お世話と報告：決めた内容でいつもどおりのお世話をし、写真や動画つきの報告が届く
  5. 鍵の返却：手渡しや書留など、安全な方法で返す

打ち合わせがあるので、留守の直前には頼めません。初めてのときは、出発の2〜3週間前には問い合わせるのが安心です。

全国331店を調べて分かったこと

当サイトの一覧には、全国47都道府県のペットシッター331店を、各グループと各店の公式サイトから載せています。数えてみると、次のことが分かりました。

  • 331店のうち311店は、全国に店舗のある4つのグループの加盟店でした。グループの公式サイトには、保険への加入や動物取扱業の登録、事前の打ち合わせなど、加盟店に共通する決まりを書いているところが多く、頼む前に確かめやすくなっています
  • いちばん多いのは東京都で84店。東京・神奈川・埼玉・千葉で194店と、6割近くが首都圏でした（東京都84・神奈川県57・埼玉県27・千葉県26・大阪府17・福岡県13店）
  • 一方で、21の県は1〜2店だけでした。店の対応エリアが住所に入らないこともあるので、地方では早めに問い合わせ、だめなときの候補（ペットホテル・動物病院の預かり）も考えておきます

登録と保険を確かめる

環境省の案内では、ペットシッターは第一種動物取扱業の「保管」にあたり、施設を持たなくても登録が必要です。公式サイトに登録番号が書いてあるか、打ち合わせのときに標識や登録証を見せてもらえるかを確かめてください。

ペットシッターSOSは「全加盟店が資格保有者であり、ペットシッター保険に加入しています」と公式サイトに書いています。保険は、お世話中の事故やけがにそなえるものです。グループに入っていない個人のシッターも、保険に入っているかを聞いてみてください。

打ち合わせで伝えること

  • 食事の種類・量・回数、食べないときの対応
  • 薬（飲ませ方、時間）。医療行為はシッターにはできないので、注射などが必要な子は動物病院と相談
  • トイレの場所と掃除のしかた、散歩のコースと時間
  • 苦手なこと（雷、来客、掃除機）、逃げやすい場所
  • かかりつけの動物病院、緊急時に連絡できる家族
  • 家の決まり（入ってほしくない部屋、エアコンの設定、戸締まり）

留守の前の準備

  • フード・ペットシーツ・猫砂を多めに用意し、置き場所を伝える
  • エアコンの温度を季節に合わせて設定し、停電のときの連絡先を決めておく
  • 脱走を防ぐため、窓や玄関の二重の扉を確かめる
  • 出発前に、シッターからの報告をどこで受け取るか（メール・LINE）を決める
  • ペットシッターとペットホテル、どちらがいい？
  • 猫の留守番：シッターに頼むときに知っておくこと

よくある質問

シッターに薬を飲ませてもらえますか？
飲み薬や塗り薬は受けるシッターが多いですが、注射や点滴などの医療行為はできません。打ち合わせで薬の内容を伝え、できる範囲を確かめてください。
鍵を預けるのが心配です。
各グループの公式サイトでは、合鍵は会社の決まりで管理し、終わったら手渡しや書留で返すと説明されています。キーボックスを使う方法もあるので、打ち合わせで相談してください。
当日や前日でも頼めますか？
初めての店舗は事前の打ち合わせが必要なので、急には頼めないことが多いです。2回目からは店舗によって前日の依頼も受けています。

あわせて読みたい

  • ペットシッターとペットホテル、どちらがいい？向く子・向かない子と組み合わせ方留守のたびに迷う「シッターかホテルか」。その子の性格と留守の長さで考えると、答えが見えてきます。
  • 猫の留守番：何日まで？キャットシッターに頼むときに知っておくこと「猫は留守番が得意」と言われますが、それは環境が変わらないからこそ。安心して出かけるための準備をまとめました。
  • トリミング・ペットホテルの送り迎えいつものお店へ、いつもの時間に。家族が付きそえない日でも、送り迎えをお願いできます。
