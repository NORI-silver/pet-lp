迷子の猫のさがし方

「ちょっと窓を開けたすきに」。室内飼いの猫にとって、外は知らない音とにおいだらけです。こわくて動けなくなり、すぐ近くでじっとしていることがよくあります。あわてず、近くから順番にさがしてください。

ペットのくらし窓口　公開 2026.11.02・更新 2026.11.02

室内飼いの猫は、まず家の中を、次に家のまわりの狭くて暗い場所を。夜や早朝に小さな声で

  1. 家の中押し入れ・家具のすき間・洗濯機の裏
  2. 家のまわり室外機の下・物置・縁の下
  3. 夜・早朝静かな時間に小さな声で
  4. 届け出写真つきでその日のうちに
  • 外に慣れていない猫ほど遠くへは行かず、家の近くに隠れていることが多い
  • 見つけたら追いかけず、しゃがんで目をそらして待つ。キャリーやせんたくネットを持っていく
  • 猫は首輪をしていないことが多いので、写真つきの届け出を早めに。猫を収容しない自治体（群馬県の動物愛護センター）もある
  • チラシは家を中心にした近い範囲に、たくさん配る

まずは家の中を、もう一度

環境省は、室内飼いの猫がいなくなったら、まず室内を徹底的にさがすよう案内しています。外に出たと思っても、家の中にいることがあります。

  • 押し入れやクローゼットの奥、たんすの上、ベッドやソファの下・中
  • 洗濯機や冷蔵庫の裏、家具と壁のすき間
  • 段ボール箱や紙袋の中、天井裏につながるすき間
  • 閉めてしまった部屋や物置（とじこめていないか）

家のまわりの、狭くて暗い場所

家の中にいなければ、家のまわりの狭くて暗い場所を重点的に（環境省の案内）。外に慣れていない猫ほど、遠くへは行かずに隠れていることが多いです。

  • エアコンの室外機の下・裏
  • 物置の中や下、車の下やタイヤの上
  • 植え込みの中、生け垣の根もと
  • 縁の下、建物と建物のすき間、ブロック塀の裏
  • となりの家の庭や駐車場（ひとこと声をかけて、見せてもらう）

懐中電灯で照らすと、猫の目が光って見つけやすくなります。呼んでも出てこないことが多いので、声だけでなく、目でさがしてください。

さがす時間とさがし方

  • あたりが静かになる夜や早朝に。昼間は人や車の音で出てこないことがあります
  • いつもの呼び方で、小さめの声で名前を呼ぶ。大声で追いかけるとさらに逃げてしまいます
  • おやつの袋をふる音、いつも使っている食器の音など、ふだん聞いている音を
  • 見つけたら、しゃがんで目をそらし、近くに来るのを待つ。キャリーやせんたくネットを持っていくと、抱いたときに逃げられにくい
  • 玄関や窓の近くに、いつもの毛布を置いておく

届け出もその日のうちに

猫は首輪をしていないことが多く、保護されても飼い主が分かりにくいので、写真つきの届け出を早めにしておきます。連絡するのは、動物愛護センター・保健所、警察、市区町村、清掃の担当、近くの動物病院です。

ただし、群馬県の動物愛護センターのように、猫の収容をしていない自治体もあります。猫は自分でさがすことが、とくに大切です。

  • ペットが迷子になったら：届け出先と伝えること
  • 全国の動物愛護センター・保健所の一覧

外に出る猫が帰ってこないとき

外と家を行き来している猫が帰ってこないときは、事故など何かがあった可能性がある、と環境省は案内しています。近所の人に見かけていないか聞く、清掃の担当に問い合わせる、動物病院に運ばれていないか聞く、をあわせてしてください。

チラシは家のまわりに

猫は家の近くにいることが多いので、チラシは家を中心にした近い範囲に、たくさん配るほうが役に立ちます。物置や車庫を見てもらえるよう、ひとことお願いを書いておきます。

  • 迷子のチラシの作り方

見つかったら・次にそなえて

  • けががなくても動物病院でみてもらう（ノミ・ダニ、ほかの猫とのけんか）
  • 出した届け出をすべて取り下げる
  • 窓の網戸は猫が開けてしまうことがあるので、ストッパーをつける。玄関にはゲートを
  • 首輪と迷子札、マイクロチップで、飼い主の連絡先が分かるようにしておく
  • マイクロチップの登録を確かめる・変更する
  • 猫の通院の送迎

よくある質問

室内飼いの猫が外に出てしまいました。遠くに行っていますか？
外に慣れていない猫は、家の近くの狭くて暗い場所にじっと隠れていることが多いです。環境省も、物置の中、室外機の下、植え込み、縁の下、建物のすき間など、家のまわりをさがすよう案内しています。
迷子の猫は、保健所や動物愛護センターに連れていかれますか？
保護されて届けられることもありますが、群馬県の動物愛護センターのように猫を収容していない自治体もあります。届け出をしたうえで、自分でさがすことが大切です。
呼んでも出てきません。
こわがっているときは、呼んでも出てこないことがよくあります。静かな夜に、懐中電灯で照らしながら、目でさがしてください。

あわせて読みたい

  • ペットが迷子になったら：すぐにすること・届け出先・さがし方玄関を開けたすきに、散歩中にリードが外れて、雷の音におどろいて。迷子は、どの家にも起こります。東京都や群馬県は「逃がした動物を自分でさがすのは飼い主の義務」と書いていますが、何をすればいいかは、なかなか知られていません。することを時間の順にまとめました。
  • 迷子のチラシの作り方チラシは、町の人に「この子を見かけたら教えてください」とお願いするためのものです。見た人がひと目で分かって、すぐに連絡できることがいちばん大切です。
  • 迷子の犬のさがし方犬は、こわさやおどろきで走りだすと、思っていたより遠くまで行ってしまうことがあります。近くをさがすのと同時に、届け出をできるだけ早く。保護してくれた人の連絡と、あなたの届け出がつながることが、いちばんの近道です。
