# 毎日の報告の型（要（かなめ）、毎朝9時）

{{OWNER}} さんへはスマホ1画面の図で、文字は要所に1〜2行。数字は売上・問い合わせ・提携数から。

| 箱 | 中身 |
|---|---|
| 状況 | 売上・問い合わせ・提携数（きのうとくらべて）。動いた目標の鎖 |
| {{OWNER}}さんの判断 | 選ぶだけの形で、おすすめつき。なければ「なし」 |
| 困りごとと対策 | 止まっていること、だれが・いつまでに |

出す前に `python3 tools/reply_check.py <文> --diagram <図>` と `node tools/report_check.cjs <図.html>`。
