# Claude が止まったときに Codex で作業する手順

ふだんは Claude で作業します。Claude が利用上限で止まったときだけ、ChatGPT（Plus）に入っている **Codex** に頼みます。
Codex もこのリポジトリの `AGENTS.md` を読むので、同じルールで動きます。どのリポジトリでも同じ手順で使えます。

## 最初に1回だけ（Nori さんの操作）

1. パソコンかスマホで https://chatgpt.com/codex を開く（ChatGPTアプリなら左のメニューの「Codex」）。
2. 「GitHub を接続」を押して、GitHub にログインし、`NORI-silver/pet-lp` へのアクセスを許可する（「Only select repositories」で pet-lp だけ選べばOK）。
3. 「環境を作成（Create environment）」で `NORI-silver/pet-lp` を選んで保存する。設定は初期のままで大丈夫です（Python 3 があれば動きます）。
4. もし Codex のメニューが出ない・使えないと表示されたら、Claude に「Codexが使えなかった」と伝えてください。別の予備（GitHub上で別のAIを動かすしくみ）を用意します。

## 頼むとき（毎回）

1. Codex を開き、環境が `pet-lp`、ブランチが `main` になっているのを確かめる。
2. やってほしいことを普通の言葉で書いて送る。例：
   - 「トップのよくある質問に、キャンセルについての質問を1つ足して」
   - 「東京の料金表の説明文をもっとやさしくして」
   - 「〇〇のページで文字がはみ出しているのを直して」
   - 書き出しに「AGENTS.md のルールを守って、」と入れるとより確実です。
3. 終わったら変更の中身が表示されるので、よければ「PRを作成（Create PR）」を押す。
4. GitHub の PR を開いて中身を見て、よければ「Merge」。数分でサイト（pet.shiokonbu.com）に反映されます。
   - 迷ったら、マージせずに Claude が戻ってきたときに「このPRを見て」と頼めばOKです。

## 注意

- `booking/Code.gs`（予約の仕組み）が変わったPRは、マージしてもそれだけでは本番に反映されません。Apps Script への貼り直しが要るので、Claude が戻ってから一緒にやりましょう。
- 会社への送信は止めています。「送信を再開して」のような頼みごとは Codex にはしないでください。
- Codex にも利用上限があります。止まったら時間をおくか、Claude が戻るのを待ちます。
