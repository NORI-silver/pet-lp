# ペットタクシーの概算・提携フォーム・料金差の対応

## 1. サイトは概算、店舗は確定額

サイトは料金表と依頼条件をもとに概算を自動で出す。店舗が空き状況と確定額を返し、飼い主さんがその内容を承認して予約が確定する。概算を確定額や上限として出さない。COCOタクは共通の料金設定を土台に概算を出す。適用範囲を指定された例外は他店に広げない。確定額まで自動で出せないことだけを理由に受付を止めない。受付開始・送信の確認ルールは従来どおり。

## 2. 提携時に、計算に足りないことをフォームで聞く

公式の料金表と過去の回答で分かるところは入力済みにし、店舗には訂正と、概算に必要な不足項目だけをお願いする。金額が変わる条件を区別できる選択肢と具体例を使う。たとえば、迎車距離の起点・端数、往復の料金や待機時間、夜間をまたぐ場合、高速料金がかかる区間、個別見積もりの境目。既回答を聞き直さない。短い片道・待機つき往復・条件の境目など、該当する例で突き合わせる。回答で計算を直し、根拠と適用範囲を残す。

## 3. 実際の依頼で出た差を、次の修正につなげる

1. 依頼時にサイトが表示した概算（あとから再計算した額で置き換えない）と、そのときの内訳・条件を残す。
2. 店舗の確定額が届いたら、同じ経路・一般道か高速か・通行料込みか・片道か往復か・待機時間・曜日や時刻・追加条件かを揃えて比較する。同条件の差は300円以内を目標にする。差を見つけたら、条件変更や実費による差と、料金データや計算の漏れを分ける。
3. 料金データ・計算式に原因があれば、根拠のある範囲だけ更新し、その案件と前後の境目で再発防止テストを追加する。提携時の質問不足が原因ならフォームも直す。判断できないまま全店の料金を変更しない。
4. 個別の依頼や連絡先は公開リポジトリに入れない。共有するのは匿名化した再現例・原因・修正・次の確認事項。店舗への追加連絡は既存の送信ルールに従う。
