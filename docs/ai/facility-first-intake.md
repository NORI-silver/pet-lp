# [E] 施設の比較から初回申込みまでの共通仕様

2026-11-28 の Nori の方針。ペットタクシーと同じく、必要な条件を入れ、利用者が「うちの子が利用できるか・最初に何を受けられるか・いくらか」を申込前に判断できるようにする。店舗一覧や外部リンクだけで終わらせない。タクシーの既存計算・受付とは別の機能。

## 比較と申込みを分ける

1. まず比較に必要な条件だけ聞く。しつけは市区町村、受け方、困りごと、犬種・体重・月齢。名前、電話、詳細住所などは申込時まで不要。希望日時・ワクチンの詳細などは判定や申込に必要なときだけ聞く。
2. 事業者 × メニュー単位で表示する。初回の相談のみ、初回から実技、体験預かり、通常レッスン、要確認を混同しない。相談が推奨という記載を必須・不要のどちらにも読み替えない。出張は所在地ではなく明記された訪問範囲で判定。年齢や体重の明示条件だけ除外し、犬種や噛みつきへの対応が不明なら要確認とする。
3. 初回に払う料金を表示。税込・回数・所要時間・出張費・入会金を分ける。継続料金や任意追加は初回と分け、未確認の追加費用があれば確定総額とは出さない。価格、申込み条件、公式の根拠と確認日をメニューごとに保存する。機械抽出候補だけでは公開しない。
4. ボタンは体験・相談・確認のどれかを区別する。初回不可の会員専用予約には送らない。公式の問い合わせ先へ進む段階は「予約確定」ではない。比較画面を操作しただけではメールや情報を外部に送らない。

## 今回の実装と次のカテゴリ

- しつけの全国・千葉入口から、千葉の一部で比較できる。既存一覧はそのまま。データは `tools/trainer_compare.json`。事業者・市・メニュー単位で根拠がそろったものを追加する。掲載対象外の地域を「受入不可」とは表示しない。
- シッター：訪問の場所、動物・頭数、希望日時・訪問回数、必要な世話 → 初回面談と当日料金、出張・鍵受け渡し等の加算を分ける。
- 老犬ホーム：短期・長期・終生、動物・体重、介護・投薬・医療の内容 → 見学や審査、初月と月額、医療・送迎費、受入条件を分ける。
- 葬儀：地域、体重・動物の種類、訪問／施設、立ち会い・返骨 → 該当プランの料金、追加費用、日時確定の手順を分ける。
- 共通の前提は、提供事業者が契約・実施の主体。初版は公式への導線のみで、サイト内の予約確定、代金受領、成約課金は実装しない。将来追加する場合は契約主体、決済、キャンセル、許認可の要否を個別に確認する。飼い主の運送・宿泊手配は別扱い。ここで他カテゴリを変更しない。
