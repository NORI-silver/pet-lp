# 記入例：ペットのくらし窓口（pet.shiokonbu.com）

`docs/ai/framework/README.md`（どの事業にも使える型）の、ペットのくらし窓口での記入例です。章の番号は型と同じ。
数字の目標・事例のくわしい中身・相手の名前は公開しないので、非公開の pet-db `docs/operating-private.md` に置いています。

## 0. 4つの目線の中身

| 目線 | このサイトでの問い |
|---|---|
| ビジネス | 問い合わせ・提携・売上に近づくか（力を入れる順：タクシー → 葬儀 → しつけ → 老犬ホーム → シッター → トリミング） |
| 使う人 | 飼い主さんがスマホで、最初の1画面で答えか探しものに着くか。文字の壁・多い入力欄はないか（AGENTS.md「品質の決まり」B） |
| 集客 | 検索で来た人の問いに、よそにない答え（くらべる表・おすすめの理由・事業者や自治体に聞いて分かったこと）で答えているか。公式の情報の書き写しだけになっていないか |
| 提携先 | 事業者・自治体の手間が少なく、得があり、その先の飼い主さんの気持ちで話しているか |

## 1. 目標の鎖

提携先を増やす → 独自で信頼できる中身（事業者・自治体への質問、写真の提供、くらべる表）→ 被リンク（自治体・団体・メディア）→ 検索で来る人 → 問い合わせ → 予約の確定 → 売上（手数料は電気通信事業の届出のあと）

## 2. 役割の割り当て

| 役 | 誰が |
|---|---|
| 司令塔・報告役 | プロジェクトのコーディネーター（毎朝の報告は型の4章の3部で） |
| 問いかけ役 | 毎週月曜の見回りのスレッドと、毎朝の報告の前の点検 |
| 設計役 | 分野・仕事ごとのスレッド（提携・問い合わせの導線・SEO・被リンク・避難・迷子・火葬・全分野の網羅など） |
| 批判役 | 仕事ごとに別のエージェント（Claude の別エージェント、または ChatGPT・Gemini・Muse に同じ決まりで頼む） |
| 見張り役 | Mac の毎晩のメール確認（返信の遅れ）と、毎週のデータの穴の一覧 |
| ほかのAI | SNS は ChatGPT。どのAIも `docs/ai/README.md` の手順で動く |

## 3. ペルソナ（分野をまたぐ）

| ペルソナ | どんな時 | 最初にほしいもの | 関わる分野 |
|---|---|---|---|
| 夜中に急病 | 23時、犬がぐったり、車がない | 開いている病院と行き方を2タップで | 病院・緊急・タクシー |
| 老犬の介護中 | 15歳・20kg・寝たきりに近い | 介護できる所と運べる車 | 老犬ホーム・シッター・タクシー |
| 亡くした直後 | 今夜、何をすればいいか分からない | 今日やることと、近くの火葬の料金の幅 | 葬儀・自治体 |
| 大型犬と引っ越し | 35kg・2頭・県をまたぐ | 乗せられる会社と概算 | タクシー・病院（引っ越し先） |
| 遠くへ連れて行く | 猫を数百km先の実家・移住先へ | 長い距離を受ける会社、往復か片道か | タクシー |
| 旅行・入院で預ける | 猫2匹・薬あり・3泊 | 合うホテル・シッターの候補 | ホテル・シッター |
| 迷子 | 今朝いなくなった | 今日・明日にやること、その町の窓口、民間の捜索 | 迷子・自治体 |
| 災害 | 台風が来る、大型犬がいる | うちの子が入れる避難所 | 避難 |
| 初めて迎える | 猫を飼いたい、一人暮らし | 迎えられる条件と場所 | 譲渡・しつけ・病院 |
| 近くに会社がない地方の人 | お迎えの県に会社がない | 県外から来てくれる会社、ほかの手段 | タクシー |

毎週の過不足の点検に使うもの：Search Console の検索の言葉、予約シートの問い合わせと「需要の記録」、提携先からの相談、フォームの離脱（GA）。

## 7. マッチングの対応表（エッジケース）

全分野の正本の表は pet-db `docs/match-schema.md`（穴の数は `python3 tools/match_gaps.py` で作り直す）。要点：

| うちの子・場面 | 飼い主さんにどう聞くか | 事業者からもらうデータ | 関わる分野 |
|---|---|---|---|
| 大型犬・超大型 | 体重（kg） | 1頭の上限kg、大型犬の頭数、ケージ・部屋の大きさ | タクシー・ホテル・トリミング・老犬ホーム・火葬 |
| 2頭以上・犬と猫いっしょ | 頭数と動物 | 同時に受ける頭数、ちがう動物を一緒にできるか、頭数で料金 | タクシー・ホテル・シッター・火葬 |
| 猫だけ・うさぎ・鳥・爬虫類 | どの動物（1つ選ぶ） | 受ける動物の一覧（書いていない＝不明） | 全分野 |
| シニア・介護・寝たきり・持病・薬 | うちの子にあてはまるもの | 介護・投薬・ストレッチャー・動物看護師 | タクシー・ホテル・シッター・老犬ホーム |
| かむ・ほえる・こわがり | うちの子にあてはまるもの | 受けるか・個室か | トリミング・ホテル・しつけ |
| 夜中・早朝・当日 | 日時 | 受付時間・当日の締め切り・割増 | タクシー・病院・火葬 |
| 長い距離・県をまたぐ | お迎えと行き先 | お迎えの範囲km・行き先の範囲・長距離の料金 | タクシー・出張の分野 |
| 飼い主さんが乗らない・何人も乗る | 同乗の人数（0人も） | ペットだけの送迎・同乗の上限 | タクシー |
| ケージがない・車いす | ケージの有無・車いす | ケージの貸し出し・車いすで乗れるか | タクシー |
| お支払い | カードを使いたい人だけ | お支払いの方法と時期 | 全分野 |
| 来てほしい | 来てほしい市区町村 | 来てくれる地域の市区町村 | 往診・シッター・訪問火葬・出張トリミング |
| 避難所 | 市区町村・動物・大きさ | 受ける動物・大きさ・同行か同伴か・飼う場所 | 避難 |
| 迷子 | いなくなった市区町村・日 | 窓口・保管の日数・民間の捜索の料金 | 迷子 |

## 分野どうしのつながり

飼い主さんの一生の流れでつなぐ。案内は必要な場面にだけ置き、分野ごとに話を分ける決まりは守る。

- 病院 ↔ タクシー：夜間・通院・大型犬の送迎。
- 老犬ホーム・介護 ↔ タクシー：入所・見学・通院の送迎。老犬ホームの提携先には「送迎も合う会社が見つかる」を得に。
- 火葬・霊園 ↔ タクシー：亡くなった子を火葬場へ運ぶ、訪問火葬が来られない地域。言い方はとくにやさしく。
- 提携先どうしの紹介：受けられない遠方・分野の依頼をほかの提携先へ。提携の得になり、提携が増えるほど価値が上がる（手数料は届出のあと）。

## 9. 判断の線引き（この事業）

- AI が決めて報告：元に戻せること、お金を使わないこと、提携先とお金の話をしないこと（AGENTS.md の決まりの中で）。
- Nori さんに1文で案を出す：提携先とのお金の話、電気通信事業の届出など役所への提出、お金を使うこと、会社への送信の再開、本番データの削除。
- 今の提携先には、こちらから連絡しない（相手から来たときは答える）。足りない項目は、提携先が自分で入る掲載情報のページに欄を足して待つ。
