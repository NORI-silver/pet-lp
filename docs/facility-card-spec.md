# [E] 事業者カード：利用者が選ぶための情報の型

## カードの順番

1. 店舗名、所在地または訪問エリア、掲載許諾がある実際の写真。写真に重ねるのは、利用者に有益で、事実と適用条件を確認できた強みを1〜2個だけ。
2. 表面は、受け入れの上限・例外、日時の条件、条件に合った料金とカテゴリ別の決め手。選んだ絞り込み条件が、なぜ当てはまるかを同じデータから表示する。判断を左右する注意点は表面に残す。
3. 「詳しく見る」は初期状態で折りたたむ。内訳、追加料金、キャンセル、初回面談、必要書類、資格、利用中の運用、緊急時対応、出典と確認日を必要に応じて表示。
4. Google の口コミは既存のタクシーと同じサイト内導線で、取得できる対象だけ。体験談を現在の設備・規則や絞り込みの根拠にしない。公式サイトのボタンは残すが、比較に必要な回答の代わりにしない。既存のタクシー料金比較・申込導線と、施設へのタクシー料金リンクは維持する。

### 適合・日時・料金のルール

- 適合は「対応」「条件付き・事前相談」「非対応」「未確認」を区別。「大型犬可」が50kg可を意味するとは限らない。明記された条件だけ適合に使う。上限15kgと15kg未満も区別する。店舗・サービス・プランをまたいで条件を転用しない。
- 検索後は「合う理由」と「予約前に確認すること」を、利用者が選んだ条件に沿って短く表示する。未確認は不適合と決めつけないが、適合結果に混ぜない。条件に合う候補がなくても、必須条件は緩めず、利用者が変更を選んだ希望条件だけ別の候補を提示する。
- 受付時間、当日相談や予約方法、実際の空きは別項目にする。実在庫や日時を確認できない限り、希望日に予約できると表示しない。
- 料金には税区分、単位、対象条件を付ける。必須の加算が揃うときだけ総額／具体的な利用例を表示し、それ以外は基本料と確認が必要な加算を分ける。送料・出張・時間外・初回・体重区分の未確認値を0円扱いしない。
- 情報ごとに対象店舗・サービス・プラン、根拠のURLまたは公開可能な確認区分、確認日を持つ。非公開メール本文等は表示しない。確認できない項目は通常時は並べず、選択条件や料金に影響するときだけ要確認を示す。

## カテゴリ別に優先するもの

| カテゴリ | カード表面 | 詳細の候補 |
| --- | --- | --- |
| ペットホテル | 体重・年齢・持病の受入条件、他犬と別室、夜間人員、宿泊料金、送迎 | 初回面談・お試し、散歩、持参食・薬、報告、繁忙期・時間外 |
| シッター・訪問介護 | 訪問範囲、料金と訪問時間、対応動物、投薬・介護の範囲 | 担当固定・顔合わせ、鍵の受け渡し、写真報告、緊急対応・保険 |
| 老犬ホーム | 受け入れる介護度、体重、初月と月額、夜間の介助、家族用カメラ・面会 | 寝たきり・夜鳴き、通院・投薬、看取り、長期・終身区分、持参品 |
| トリミング | 犬種・サイズ別料金、シニア・持病の条件、出張・送迎 | 休憩や短時間施術、苦手な子の中断基準・料金、毛玉などの加算 |
| ドッグトレーナー | 出張・通所、対応する悩み、方法、1回料金 | 飼い主同席、初回相談、必要な通い方・回数券、資格や経験 |
| ドッグラン | 屋内・屋外、区画、貸切、大型犬、利用料金 | 他犬と会わず使える条件、貸切単位、足元・雨天・証明書 |
| ペット探偵 | 対応動物とエリア、現地・遠隔、出動・捜索料金と時間 | 現地到着の条件・目安と実際の空きの区別、出動なしの費用、報告と次の対応 |
| 葬儀・火葬 | 体重別料金、個別・合同、立ち会い、返骨、訪問・来場 | 引き取りと返骨の時期、立ち会える工程、訪問不可時の代替、骨壺や加算 |
| 霊園 | 個別・合同納骨、初回費用、年間管理費、お参り | 更新・返還条件、供養・火葬とのセット内容 |
| 動物病院 | 対象動物・診療領域、夜間・救急受付、来院前の連絡要否 | 最終受付・時間外加算、対応対象外。稼働中とは断定しない |
| ペットタクシー | 既存のカード・料金比較を維持し、対応地域、体重・同乗・介助の条件、料金リンク | 深夜・迎車・待機等の加算。申込・予約・計算ロジックは本仕様の追加対象外 |

写真はホテル・シッター・老犬ホーム、葬儀・火葬で実環境の掲載可能な写真3枚以上、探偵は2枚以上を目安とする。足りない分を無関係・無許諾の写真で埋めない。非公開カテゴリを再公開しない。

## 反映と確認

カードと絞り込みで既存の同じ根拠を使い、全国ハブと県の一覧で表示が食い違わないことを確認する。まず既存の事実を優先し、未確認を埋めるために表示だけを追加しない。新しい検索URLや薄い詳細ページは作らない。個別ページの作成条件は [施設ページの型](facility-page.md) に従う。

確認ケース：50kgに対して大型犬可のみなら要確認、同じ店でトリミング送迎のみならホテル送迎にしない、防犯カメラを家族用カメラとして出さない、合同火葬で返骨不可なら返骨に適合させない、時間外費用が未確認なら総額を確定しない。スマホで写真・注記・折りたたみを確認し、口コミ・公式サイト・既存予約を壊していないことを確かめる。

初回の利用内容・料金を比較し、申込みへ進む共通仕様は [施設の比較から初回申込みまで](ai/facility-first-intake.md) を参照。
