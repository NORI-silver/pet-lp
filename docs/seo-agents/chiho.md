# Agent E 地方（/area/ と43道府県）

県名つきの検索数はまだ測っていない。予約はできない県なので、情報ページとしての訪問を増やす担当。
元ファイル：`tools/prefs.py`（県のデータ）・`tools/gen_areas.py`（作り方）・`tools/emergency.json`（夜間の病院・搬送の会社）。

## やることの候補（上から）
1. 人口の多い県から（大阪・愛知・福岡・北海道・兵庫・京都・静岡・広島・宮城）：夜間の動物病院・搬送の会社が公式サイトどおりで、`checked` が新しいか。
2. 県ページの title・説明文に「◯◯ ペットタクシー」「◯◯ 夜間 動物病院」。
3. 料金の例がない31県：全国の事業者一覧で公式サイトの料金が確かめられた県だけ、社名なしで足す。
4. どのページも「この県からのお迎えはまだ予約できない」の文は残す。県ページは noindex にしない。
5. 検索数がわかったら（キーワードプランナー）、`docs/seo-agents.md` の表に書き、多い県を先にする。
